# xglance-legal

Public pages for the xGlance app, served by GitHub Pages:

- Privacy Policy — https://kamurandogan.github.io/xglance-legal/privacy/
- Terms of Use (EULA) — https://kamurandogan.github.io/xglance-legal/terms/
- Support — https://kamurandogan.github.io/xglance-legal/support/

`assets/site.css` is generated from the app's theme file
(`dev_docs/design/themes/terminal_dark.json` in the app repo); do not edit its colors by hand.
`app-ads.txt` lives at the domain root (`kamurandogan.github.io/app-ads.txt`, repo `kamurandogan.github.io`).
